# 日々（Hibi）日语学习

面向个人使用的响应式日语学习 Web 应用。第一阶段从 N5 与可跳过的假名入门开始，以“到期复习优先、在语境中学习、必须主动输出”为核心。

## 已完成的第一条学习闭环

- 手机和电脑响应式界面
- 今日学习任务与默认 30 分钟计划
- 默认每日 10 个新文法、50 个新单词，可自行修改
- 可跳过的假名入门与浏览器日语发音
- 首批 N5 文法和单词示例内容
- 文法造句与 AI 反馈入口
- OpenAI、Anthropic、Gemini、OpenAI 兼容接口配置
- 浏览器本地保存个人设置
- PWA manifest

## 本地运行

```bash
npm install
npm run dev
```

打开 <http://localhost:3000>。

## 构建

```bash
npm run lint
npm run build
npm start
```

Linux 服务器需使用 Node.js 20.9 或更高版本。API Key 目前只保存在用户浏览器的 localStorage 中，不会进入源码或 Git；浏览器会在需要判定时把密钥发送到同源服务端。正式公网部署必须启用 HTTPS。

## 当前边界

这是用于验证学习体验的第一版，不是完整 N5 课程。复习页已经留出调度器入口，但真实 FSRS 状态、数据库、账号体系、内容导入和服务端加密密钥存储将在后续迭代加入。

当前示例内容为项目内原创小规模样本。后续接入 JMdict / KANJIDIC2 时，将保留数据来源、许可、版本和内容修订记录。
